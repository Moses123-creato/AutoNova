# skills

This folder holds the reusable skills the agents on this project follow. Think of a skill as a "how we do this here" file: once a way of working proves itself, it gets written down here so the next agent does not have to rediscover it.

What lives here:
- `architecture-skill.md` — how to approach architecture design and write architecture specs.
- Whatever else we earn: a sync skill for maintaining `build.md`, a debug skill for the error log, and so on. The agent that discovers the pattern writes the skill.

Rules:
- Follow the skills here. They are part of the job, not suggestions.
- If you find yourself doing something for the second time that is not yet written down, write it as a skill.
- Keep skills short and concrete: what, when, and an example. No fluff.
- This folder is maintained by the agents doing the work. Do not expect the owner to fill it in.
